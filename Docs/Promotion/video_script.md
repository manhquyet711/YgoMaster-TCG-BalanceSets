# Video script: how to download and set up the mod

**Title:** Play Classic Yu-Gi-Oh! Character Decks in Master Duel (Offline Mod Setup)
**Length:** about 5 minutes · **Format:** screen recording with voiceover, 1080p

**Record beforehand:**
- A clean Windows desktop with Master Duel installed from Steam and its tutorial finished.
- The release zip downloaded.
- Some gameplay clips: the Solo folders, a Balanced Characters map, and a duel with Joey vs Kaiba.

**Don't show** your Steam account name, your email, or any personal folders.

---

## 1. Hook (0:00 - 0:20)

**On screen:** a gameplay montage: Yugi vs Kaiba, Exodia, the Solo menu with the folders.
**Text:** "Classic character decks · Master Duel · Offline"

**Voiceover:**
"What if you could pick Yugi, Kaiba, Joey or Pegasus and duel with their classic decks, balanced against each other, inside Master Duel? This free offline mod does exactly that. Here's how to set it up in five minutes."

## 2. What you get (0:20 - 0:55)

**On screen:** the Solo menu. Open each folder for a second.

**Voiceover:**
"In Solo, under Stories, you get three character modes.
- Balanced Characters: fifteen old-school decks by Reddit user Rosehn.
- Goat Era Duelists: eight decks made only of 2005 Goat format cards.
- Duel Royale: Konami's seven official Duel Royale decks.

The TCG Campaign is here too, with the real ban list of every era. Everything runs offline. It never connects to Konami's servers, and your real account isn't touched."

**Text:** "Offline only · Your real account is not used"

## 3. Before you start (0:55 - 1:30)

**On screen:** the Steam library page for Master Duel, then the in-game title screen.

**Voiceover:**
"You need three things.
- First, Master Duel from Steam, fully downloaded. Start it once normally and finish the tutorial, so all the game data is on your PC. Then close it.
- Second, Windows with .NET Framework 4.8. Windows 10 and 11 already have it.
- Third, the mod's zip from GitHub. The link is in the description."

**Text:** "1. Master Duel (Steam), tutorial done · 2. Windows 10/11 · 3. The mod zip"

## 4. Download (1:30 - 2:00)

**On screen:** the GitHub Releases page. Click the latest release, then the `.zip` asset. Show the download finishing.

**Voiceover:**
"Open the Releases page on GitHub, and under the newest version, download the zip file. Only download it from this page. If Windows warns about an unknown app later, that's normal for small community tools. Only continue if the file came from this GitHub page."

## 5. Find your Master Duel folder (2:00 - 2:35)

**On screen:**
1. In Steam, right-click Master Duel.
2. Manage.
3. Browse local files.
4. The folder opens; highlight `masterduel.exe`.

**Voiceover:**
"In Steam, right-click Master Duel, choose Manage, then Browse local files. This is the game folder, the one with masterduel.exe in it. Keep this window open."

## 6. Extract the mod (2:35 - 3:10)

**On screen:**
1. Right-click the zip, then Extract All.
2. Drag the `YgoMaster-BalancedCharacters` folder into the game folder, next to `masterduel.exe`.
3. Show the final layout: `masterduel.exe` and `YgoMaster-BalancedCharacters` side by side.

**Voiceover:**
"Extract the zip. Inside is a folder called YgoMaster-BalancedCharacters. Move that whole folder into the game folder, right next to masterduel.exe. Not inside another folder. Right next to it."

**Text:** "The mod folder goes NEXT TO masterduel.exe"

## 7. Start the game (3:10 - 3:50)

**On screen:**
1. Open the mod folder. It shows only `Data` and `Start Game.exe`.
2. Double-click Start Game. The window opens.
3. Point at the Stories Modes list and the settings, then click the yellow Start Game button.
4. Master Duel starts.

**Voiceover:**
"Open the mod folder. You'll see just Start Game. Double-click it. This window is also where the settings are: starting gems, rewards, and the list of character modes. When you're ready, press Start Game. It starts the offline server and then Master Duel for you. From now on, always start the game with Start Game, not from Steam."

**Text:** "Always launch with Start Game.exe"

## 8. Play (3:50 - 4:30)

**On screen:**
1. Solo, then Stories, then Balanced Characters.
2. Pick Joey.
3. The map shows "vs Kaiba", "vs Mai" and so on.
4. Open a node, show Confirm Opponent's Deck, then Play.
5. A short duel clip.

**Voiceover:**
"Go to Solo, then Stories, then Balanced Characters. The gate you pick is the character you play. Each battle on the map is a different opponent. You can see their deck before you start. Both decks are fixed, so it's skill and luck, not collection. Beat every opponent to clear the character. Your deck list also gets a copy of every deck, so you can study the recipes."

## 9. Troubleshooting (4:30 - 4:55)

**On screen:** show each tip as text.

**Voiceover:**
"If something doesn't start:
- Make sure Master Duel is closed before pressing Start Game.
- Make sure the mod folder sits right next to masterduel.exe.
- If you get an error, the details are in the LaunchLogs folder. It's hidden, so turn on Show hidden items in Explorer to see it.
- Questions go to the GitHub page."

## 10. Outro and credits (4:55 - 5:10)

**On screen:** a credits card.

**Text:**
- Decks: u/Rosehn (Reddit)
- YgoMaster: pixeltris
- TCG Solo Campaign: vngudu
- Duel Royale decks: Konami
- Fan-made and free; not affiliated with Konami.

**Voiceover:**
"Huge thanks to Rosehn for the decks, and to the YgoMaster and TCG Campaign authors. Links are below. Have fun duelling!"
